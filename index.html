COMMENT JOUER

Ouvre les cases pour révéler les chiffres ; chacun indique les mines voisines.

Souris : clic gauche pour révéler, clic droit pour poser un drapeau, clic molette pour recommencer. Sur mobile, maintiens une case pour poser un drapeau.

Au clavier : flèches pour bouger, Entrée/Espace pour ouvrir, F pour poser un drapeau, R pour recommencer.

Gagne en ouvrant toutes les cases sans mine. En classé, résous avant le chrono pour monter ; une défaite ne fait pas perdre de rang.
